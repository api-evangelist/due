Due (Due Network, opendue.com) is a London-founded payments infrastructure company (backed by Speedinvest) that provides a single API for borderless money movement. Its platform bridges traditional banking rails with blockchain networks: cross-border transfers and fiat<->stablecoin on/off-ramps (USDC, EURC, USDT) across 80+ countries plus SWIFT in 150+, programmable virtual accounts for fund collection, a public FX rate engine, automated KYC/KYB onboarding, non-custodial MPC wallets (Vault), and signed webhooks. The REST API is documented on due.readme.io and served from api.due.network.

**Areas:** Payments · Cross-Border Payments · Stablecoins · Fintech · Virtual Accounts · Foreign Exchange · KYC · Wallets

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Due: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
